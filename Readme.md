# Página web con comandos básicos de git

Repositorio planteado para funcionar como una guia rapida basica para ver los comandos de git.

Con este repositorio tenemos como objetivo poner en practica lo aprendido en el taller de git sobre trabajo colaborativo, branches, commits, etc. para desarrollar proyectos de forma ordenada, prolija y colaborativa.





## Dentro de la página web tenemos las secciones:
- Configurado de email y nombre.
- Comandos para iniciar repositorio y ver estados.
- Comandos de agregar cambios y commits.
- Comandos de branches.
- Comandos de GitHub y repositorios remotos.
- Comandos de flujo de trabajo básico.
