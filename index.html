Guía de comandos básicos de Git

Aprendé a utilizar Git desde cero.

1. Configuración

Permite configurar los datos del usuario en Git.

Configurar nombre de usuario

git config --global user.name "Tu Nombre"

Configurar correo electrónico

git config --global user.email "tu@email.com"

Ver la configuración

git config --list

2. Repositorios

Permite crear repositorios y consultar su estado.

Inicializar un repositorio

git init

Clonar un repositorio

git clone URL

Ver el estado del repositorio

git status

Ver el historial de commits

git log --oneline

3. Gestión de cambios

Permite preparar, guardar y revisar modificaciones.

Agregar todos los cambios

git add .

Agregar un archivo específico

git add archivo.txt

Guardar cambios en un commit

git commit -m "Descripción del cambio"

Ver diferencias

git diff

Descartar cambios locales de un archivo

git restore archivo.txt

4. Ramas (Branches)

Las ramas permiten trabajar en funcionalidades diferentes.

Listar las ramas

git branch

Crear una rama

git branch nueva-rama

Cambiar de rama

git switch nueva-rama

Crear y cambiar de rama

git switch -c nueva-rama

Fusionar una rama

git merge nueva-rama

5. GitHub y repositorios remotos

Permite conectar tu repositorio local con uno remoto.

Conectar un repositorio remoto

git remote add origin URL

Ver los repositorios remotos

git remote -v

Subir cambios

git push origin main

Descargar e integrar cambios

git pull

Descargar referencias remotas

git fetch

6. Flujo de trabajo básico

Esta es una secuencia habitual para guardar y subir cambios.

  1. Consultar el estado: git status
  2. Preparar los cambios: git add .
  3. Crear un commit: git commit -m "Mi cambio"
  4. Subir los cambios: git push origin main
